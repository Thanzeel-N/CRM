How to Test with Real Webhooks

  1. Install ngrok (free tunnel tool): npm install -g ngrok
  2. Start tunnel: ngrok http 8000
  3. Copy the https://xxxx.ngrok.io URL
  4. Go to Connect Meta Ads tab and paste as Callback URL
  5. Run a test lead from a Facebook Lead Ad Preview or the simulator above
  6. Watch the lead appear in your Pipeline Board in real time ✅

The Webhook Tester tab bypasses Meta entirely and creates the lead directly — perfect for testing your staff assignment and status flows.
